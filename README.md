# The Conscious Club Archive

A static, GitHub Pages-ready archive of 11 completed Music League seasons.

## Preview locally

Run any static file server in this directory, for example:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Publish with GitHub Pages

Push the contents of this directory to a GitHub repository, then enable **Settings → Pages → Deploy from a branch** and select the branch root.

The public site contains names, submissions, vote totals, and comments from the league exports. Review it with the group before publishing.
